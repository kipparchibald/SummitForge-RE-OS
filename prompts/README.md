# Prompts

Reusable Grok prompts for Archibald-Bagley workflows.

- `idaho-contract-filler.md` — blank template for future Idaho real estate contracts. No pre-filled property data. Seller is variable (Rigby 106 LLC, Cozma, etc.).
- `adair-ghost-listing-contract-filler.md` — specific version for the Adair Homes ghost listings (Winchester + Teton) in Teton Heights Div 6.

How to use: copy the contents into a new Grok chat, or reference the file. Then answer the questions one at a time.
